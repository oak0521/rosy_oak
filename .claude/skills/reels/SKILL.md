# 릴스 1편 기획

## 먼저 읽을 것

작업 전에 반드시 읽으세요 (매번, 기억에 의존하지 말 것):

- `creator/strategy/02-growth-engine.md` — 참여 장치. **매 편 최소 3개 배치**
- `creator/playbooks/short-reels.md` — 포맷 F1~F5의 초 단위 구조
- `creator/playbooks/hooks.md` — 훅 라이브러리
- `creator/playbooks/captions.md` — 본문·해시태그 템플릿
- `creator/playbooks/subtitles-and-music.md` — 자막 규칙, 이중 배포 규칙
- `creator/strategy/05-child-safety.md` — 노출 원칙. **위반 소지가 있으면 반드시 지적할 것**

## 입력 확인

사용자가 준 것을 확인하세요.

- 컨택트시트 이미지 → **실제로 보고** 어느 클립 몇 초에 뭐가 있는지 파악
- `inventory.json` → 클립 길이·해상도·촬영 시각
- 상황 설명 → 화면에 안 나오는 정보(비용, 감정, 아이 컨디션)

**컨택트시트가 없으면 먼저 요청하세요.** 화면을 못 보면 일반론밖에 못 씁니다.
`creator/pipeline/scripts/prep.sh <원본폴더>` 를 실행하라고 안내하세요.

클립 없이 기획만 요청받은 경우엔 EDL 대신 **촬영 샷 리스트**를 산출하세요.

## 산출물

`creator/pipeline/out/<날짜>_<소재>/` 에 파일로 저장하고, 요약은 채팅에 표로 보여주세요.

### 1. 기획 요약 (채팅에 표로)
| 항목 | 내용 |
|---|---|
| 포맷 | F1~F5 중 하나 + 선택 이유 |
| 필러 | P1~P4 |
| 훅 | 실제 자막 문구 |
| 길이 | 초 |
| 참여 장치 | 배치한 3개 이상을 명시 (저장/공유/댓글/DM 중) |
| 루프 설계 | 마지막 컷과 첫 컷을 어떻게 이을지 |

### 2. `edl.json`
`creator/pipeline/templates/edl.example.json` 형식.
- 클립·구간은 **컨택트시트에서 실제로 확인한 것**만 쓸 것. 추측한 타임코드를 쓰지 말 것
- 세로 출력이면 `"video": {"w":1080,"h":1920,"fps":30}`

### 3. `<이름>.srt`
- 1.5~2.5초마다 전환, 한 화면 16자×2줄 이내
- 소리 없이 봐도 100% 이해되게
- 훅 자막 / 내레이션 자막 / 속마음 자막을 구분해서 설계하고, 어느 게 어느 유형인지 EDL 노트에 표시

### 4. `captions.md`
- 인스타 본문 (첫 줄이 승부처 / 행동 유도는 **하나만** / 해시태그 8~15개, 대·중·소형 배합)
- 유튜브 쇼츠용 제목·설명
- **고정 댓글** 문안
- 협찬이면 첫 줄 `#광고` + 자막에도 노출

### 5. `music-cue.md`
구간별 무드·BPM·볼륨(dB). 현장음이 주인공이라는 원칙 유지.
인스타용은 앱 내 트렌딩 오디오를 쓰도록 안내(무음 버전 렌더).

## 마지막에 할 것

1. 렌더 명령을 알려주세요:
   `python3 creator/pipeline/scripts/render.py longform <경로>/edl.json`
2. 캡컷으로 수동 작업할 경우의 컷 순서 표도 함께 제시
3. `creator/ops/kpi-log.csv` 에 행을 추가해 두세요 (발행일·포맷·훅유형·제목)

## 하지 말 것

- 훅이 약속한 내용을 영상이 못 지키는 설계 (3초 이탈 → 계정 전체 도달 하락)
- 참여 장치를 4개 이상 욱여넣기 (행동 유도는 하나만 선명하게)
- `strategy/05-child-safety.md` 의 절대 금지 항목이 들어간 클립을 편집에 포함시키기
  — 발견하면 **먼저 지적하고** 대체 컷을 제안하세요
