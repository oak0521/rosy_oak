# 02. 성장 엔진 — 체류시간과 인게이지먼트를 설계하는 법

> 요청하신 "단순히 좋아할 만한 기획에서 끝나지 않고, 본 사람이 계정 안에 오래 머물고
> 행동하게 만드는 설계"가 이 문서입니다. 모든 기획은 여기 있는 장치를 **최소 3개** 넣고 시작합니다.

## 2026년 알고리즘이 실제로 보는 신호

인스타는 2025년까지의 좋아요·댓글 중심에서 벗어나, **체류시간·완시청·저장·공유(DM)**를
도달 배분의 핵심 신호로 쓰고 있습니다. 유튜브 쇼츠도 **시청 지속률**이 최우선이고,
80% 이상 시청 시 추천 확률이 크게 오릅니다.

신호별 난이도와 가치:

| 신호 | 도달 기여 | 만들기 난이도 | 우리의 무기 |
|---|---|---|---|
| **공유 (DM)** | 최상 | 높음 | "이거 남편/친구한테 보내야 해" 트리거 |
| **저장** | 최상 | 중간 | 검증 리스트·지도·준비물 (2층 콘텐츠의 본업) |
| **완시청·재시청** | 상 | 중간 | 루프 편집, 자막 리듬, 정보 후행 배치 |
| **댓글** | 중 | 낮음 | 답이 정해진 질문, 빈칸 채우기 |
| **좋아요** | 하 | 낮음 | 신경 쓰지 말 것 |
| **팔로우** | — | — | 위 5개의 **결과**이지 목표가 아님 |

**좋아요 수를 성과로 보지 마세요.** `ops/metrics.md`에서 실제로 볼 지표를 정의합니다.

## A. 영상 1편 안에서의 리텐션 설계

### 0~1초: 시선 정지
첫 프레임에서 **이미 뭔가 일어나고 있어야** 합니다. 준비 동작·인사·로고 인트로 = 즉사.

- ✅ 움직임 한가운데서 시작 (아이가 이미 뛰고 있음, 물건이 이미 쏟아지고 있음)
- ✅ 화면 상단에 텍스트 훅이 **이미 떠 있음** (뒤늦게 타이핑되면 늦음)
- ❌ "안녕하세요~" / 검은 화면 페이드인 / 브랜드 인트로

### 1~3초: 약속
"이걸 끝까지 보면 뭘 얻는지"를 명시합니다. 여기서 **끝까지 볼 사람과 나갈 사람이 갈립니다.**

- "이 중에 기저귀 갈이대 없는 데가 하나 있어요"
- "3번이 제일 중요한데 다들 모르더라고요"
- "결론부터 말하면 25개월은 아직 무리였어요"

### 3초~끝: 정보 후행 배치 (retention gate)
가장 궁금한 답을 **뒤에** 둡니다. 단, 미끼로만 끌지 말고 중간중간 작은 보상을 줘야 합니다.

```
 0s ────────── 3s ────────── 8s ────────── 14s ───── 18s
 훅        약속+긴장       보상1         보상2      최종답
 (움직임)  ("3번이 핵심")  (정보 A)     (정보 B)   ("3번은...")
```

### 마지막 1초: 루프 설계
**끝 화면과 첫 화면이 자연스럽게 이어지게** 편집하면 시청자가 무의식적으로 2~3회 반복 재생합니다.
이게 완시청률을 1회 재생만으로 만들 때보다 훨씬 크게 올립니다.

구현법 3가지:
1. **동작 루프** — 마지막 컷의 움직임 방향 = 첫 컷의 움직임 방향
2. **문장 루프** — 마지막 자막이 첫 자막의 앞부분이 됨 ("...그래서 다음엔 여기로 갔어요" → 첫 컷 "여기 갔다가")
3. **화면 루프** — 마지막 프레임 색·구도를 첫 프레임과 맞춤

### 자막 리듬
자막은 정보 전달용이 아니라 **눈을 화면에 붙잡아 두는 장치**입니다.
- 1.5~2.5초마다 자막이 **바뀌어야** 합니다. 한 자막이 4초 이상 머물면 이탈 지점이 됩니다.
- 소리 없이 봐도 100% 이해되게. (릴스 시청의 상당수는 무음)
- 자세한 규칙은 `playbooks/subtitles-and-music.md`

## B. 행동을 유도하는 장치 (매 편 최소 3개)

### 1. 저장 트리거
저장은 "지금은 못 하지만 나중에 할 일"일 때 눌립니다.

| 장치 | 문안 예시 |
|---|---|
| 체크리스트 | "0~2세 데리고 갈 때 챙길 7가지 — 저장해두고 나갈 때 확인하세요" |
| 지도·리스트 | "서울 서남권 영아 동반 카페 5곳" |
| 조건부 정보 | "24개월 넘으면 이건 안 통해요" (지금 22개월인 사람이 저장) |
| 준비물 | "이유식 들고 나갈 때 이 조합이면 안 상해요" |

명시적으로 말하세요: **"저장해두세요"는 실제로 저장률을 올립니다.** 단 1회, 자연스럽게.

### 2. 공유 트리거
공유는 "**내가 하고 싶은 말을 대신 해줄 때**" 눌립니다. 정보보다 감정이 강력합니다.

| 유형 | 문안 예시 | 누가 누구에게 보내나 |
|---|---|---|
| 대변형 | "퇴근하고 돌아왔는데 애가 나를 못 알아봤어요" | 복직맘 → 복직맘 친구 |
| 지령형 | "이거 남편한테 그냥 보내세요, 설명하지 말고" | 아내 → 남편 |
| 실용형 | "주말에 여기 갈까?" | 부부 사이 |
| 반전형 | "다들 이거 사지 말라는데 저는 인생템이었어요" | 커뮤니티 공유 |

### 3. 댓글 트리거
**"어떻게 생각하세요?" 같은 열린 질문은 댓글을 못 받습니다.** 타이핑 비용이 높아서예요.
비용이 낮은 질문을 던지세요.

| 방식 | 예시 | 답변 비용 |
|---|---|---|
| A/B 택일 | "여러분은 1번이에요 2번이에요?" | 글자 1개 |
| 빈칸 채우기 | "우리 애는 ___ 앞에서만 얌전해져요" | 단어 1개 |
| 개월수 소환 | "몇 개월이세요? 저희는 25개월요" | 숫자 |
| 반박 초대 | "저는 이게 낫다고 보는데 반대 의견 궁금해요" | 의견 |
| 정보 요청 | "이런 데 또 아시는 분 댓글 주세요 다음에 갈게요" | 정보 (+다음 콘텐츠 소재까지 확보) |

**댓글 답글은 24시간 안에 전부.** 초기 계정에서 이건 알고리즘 신호이자 팬 형성 수단입니다.
답글은 한 단어로 끝내지 말고 **되물어서** 대화를 2~3턴 만드세요 — 그만큼 체류시간이 늘어납니다.

### 4. DM 트리거 (가장 강력, 가장 저평가됨)
DM은 참여 신호 중 최상위이고, 동시에 **협찬 전환과 공동구매의 실제 경로**입니다.

- "여기 위치 궁금하시면 DM 주세요, 링크 보내드릴게요"
- "이 리스트 전체는 DM으로 보내드려요. '리스트'라고만 보내주세요"
- 스토리 질문 스티커 → DM 유입

> 나중에 팔로워 3천을 넘으면 이 DM 목록이 곧 고객 명단입니다. 지금부터 쌓으세요.

## C. 계정 안에서 오래 머물게 하는 구조

한 편을 오래 보는 것보다 **여러 편을 연속으로 보는 것**이 계정 전체 도달을 더 크게 올립니다.

```
릴스 도달
   │
   ├─ [프로필 클릭 유도] 자막: "지난주 갔던 데는 프로필에 있어요"
   ▼
프로필 진입
   │
   ├─ 고정 3개가 즉시 보임 (소개 / 최고 저장작 / 시리즈 EP1)
   ▼
2편차 시청  ← 여기가 핵심. 1편만 보고 나가면 계정은 안 큽니다.
   │
   ├─ 시리즈 넘버링이 다음 편으로 끌어당김 (EP3 봤으면 EP1,2 보러 감)
   ▼
하이라이트 → 팔로우 → DM
```

**시리즈 넘버링을 반드시 쓰세요.** 「수달이네 주말 보고서 EP.7」처럼요.
넘버가 붙는 순간 사람은 앞 회차를 찾아봅니다. 낱개 콘텐츠는 그게 안 됩니다.

**콜드 오픈 예고**: 영상 끝에 다음 편 2초 티저.
"다음 주엔 처음으로 기차 타고 갑니다" → 다음 편 대기 수요 형성.

**하이라이트 구성 (프로필 체류 장치)**
| 하이라이트 | 내용 |
|---|---|
| 📍 가본 곳 | 장소별 검증 결과 아카이브 |
| 🧳 챙길 것 | 나들이 준비물 |
| 🍼 25개월 | 현재 개월수 일상 (개월수는 주기적으로 갱신) |
| 🦦 수달이네 | 시그니처 시리즈 모음 |
| 💌 협찬문의 | 미디어킷·연락처 |

## D. 하지 말아야 할 것

- **"팔로우 해주세요" 남발** — 도달에 도움 안 되고 신뢰만 깎입니다. 계정 소개 릴스에서 1회면 충분.
- **어그로 훅 + 내용 불일치** — 3초에 이탈이 몰리면 알고리즘이 그 계정 전체를 낮게 봅니다. 훅은 반드시 지켜야 할 약속.
- **다른 계정 영상 재업·짜깁기** — 인스타는 원본성(originality)을 명시적 신호로 씁니다.
- **팔로워 구매·품앗이 좋아요** — 참여율이 망가지면 협찬 단가가 오히려 떨어집니다.
  광고주는 팔로워 수보다 **ER(참여율)**을 봅니다. 카테고리 평균 대비 2배 ER이면 팔로워가 적어도 원고료를 받습니다.
- **매번 다른 컨셉 실험** — 알고리즘이 계정 주제를 학습하지 못하면 도달 대상을 못 찾습니다. 3개월은 3층 구조를 유지하세요.
- **업로드 주기 붕괴** — 주 3편 이상을 유지해야 알고리즘이 계정을 활성으로 봅니다.
  바쁜 주를 대비해 `ops/weekly-routine.md`의 **재고(backlog) 2편 유지 원칙**을 지키세요.
