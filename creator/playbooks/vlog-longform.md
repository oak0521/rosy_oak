# 롱폼 브이로그 (유튜브, 8~12분)

## 왜 롱폼도 하는가

릴스만 하면 도달은 나오지만 **자산이 안 쌓입니다.** 롱폼은 세 가지를 줍니다.

1. **검색 자산** — "25개월 키즈카페" 같은 검색어로 1년 뒤에도 유입됩니다
2. **숏폼 원재료** — 롱폼 1편에서 숏폼 3~4편이 나옵니다 (제작 효율의 핵심)
3. **협찬 신뢰도** — 브랜드는 롱폼이 있는 계정을 더 진지하게 봅니다

주 4~6시간 예산에선 **월 2편**이 적정. 촬영은 주말 나들이 때 한 번이면 됩니다.

## 구조 (10분 기준)

| 구간 | 시간 | 목적 | 내용 |
|---|---|---|---|
| **콜드 오픈** | 0:00–0:20 | 이탈 방지 | 오늘의 가장 극적인 순간을 먼저. 인사·인트로 없음 |
| **약속** | 0:20–0:45 | 시청 이유 | "오늘은 처음으로 OO에 갑니다. 결론부터 말하면 OO였어요" |
| **준비** | 0:45–2:00 | 정보+공감 | 짐 싸기, 준비물 (여기가 저장·캡처 구간) |
| **이동** | 2:00–3:00 | 리듬 | 차 안·지하철. 짧게. 지루하면 잘라내기 |
| **본편 1** | 3:00–5:30 | 몰입 | 도착~첫 반응. 아이 리액션이 중심 |
| **작은 위기** | 5:30–7:00 | 서사 | 울음, 낮잠, 예상 밖 문제 — **이 구간이 있어야 브이로그가 됩니다** |
| **해결·절정** | 7:00–8:30 | 보상 | 위기 해결, 가장 좋았던 순간 |
| **정리** | 8:30–9:30 | 정보 | 검증 7항목 요약, 총비용, 추천 여부 |
| **아웃트로** | 9:30–10:00 | 재방문 | 다음 편 예고 + 댓글 질문 |

> **"작은 위기"를 반드시 넣으세요.** 다 좋았던 하루는 브이로그로서 실패합니다.
> 아이가 울고, 낮잠 타이밍이 어긋나고, 뭘 두고 온 것 — 그게 시청자가 자기 이야기라고 느끼는 지점입니다.

## 유튜브 리텐션 장치

- **챕터(타임스탬프)를 반드시 넣으세요.** 설명란에 `0:00 콜드오픈` 형식으로.
  시청자가 원하는 구간으로 점프해도 시청시간은 유지되고, 검색 노출에도 유리합니다.
- **30초마다 시각적 변화** — 컷 전환, 자막 스타일 변화, 인서트 컷. 같은 앵글이 15초 넘게 이어지면 이탈합니다.
- **말로 하지 말고 보여주기** — "힘들었어요" 대신 힘든 장면 + 자막
- **댓글 유도는 아웃트로 아닌 8분경**에 (끝까지 안 본 사람도 댓글 달게)

## 촬영 샷 리스트 (나들이 1회분)

찍을 게 정해져 있으면 촬영이 10분 안에 끝납니다. **핸드폰 메모에 복사해두세요.**

**필수 (이거 없으면 편집이 안 됨)**
- [ ] 출발 전 짐 싸는 손 (탑다운)
- [ ] 문 나서는 뒷모습
- [ ] 이동 중 창밖 + 아이 손
- [ ] 도착 순간 첫 반응 (**가장 중요. 무조건 찍기**)
- [ ] 공간 전경 패닝 1회
- [ ] 검증 항목별 컷 7개 (수유실/기저귀대/유모차 동선/이유식/소음/주차/가격)
- [ ] 아이가 몰입한 롱테이크 20초 이상 (편집 때 늘려 쓸 여유분)
- [ ] 위기 순간 (울음·낮잠·사고) — 찍기 미안해도 찍어두기, 쓸지는 나중에 결정
- [ ] 나오는 뒷모습

**있으면 좋은 것**
- [ ] 부모 셀프 코멘트 10초 (차 안에서 "지금 상황은…")
- [ ] 아이 시선 높이 로우앵글 (바닥에 폰 두고)
- [ ] 타임랩스 (한자리 고정 30초)
- [ ] 인서트: 음식, 신발, 티켓, 간판(단, 위치 특정 주의 → `strategy/05-child-safety.md`)

**촬영 기본기**
- 가로 4K로 찍으면 세로 크롭 여유가 생깁니다. 단, 세로 전용 컷도 몇 개는 따로 찍어두세요.
- 한 컷은 **최소 5초**. 3초짜리 클립만 잔뜩 있으면 편집이 불가능합니다.
- 아이를 부르지 말고 **기다리세요.** 카메라 보고 웃는 컷보다 몰입한 컷이 훨씬 좋습니다.
- 소리가 생명입니다. 바람 부는 날은 폰 마이크를 손으로 가리지 말고, 조용한 순간을 5초 이상 확보하세요.

## 롱폼 → 숏폼 파생 규칙

롱폼 1편에서 숏폼 3~4편을 뽑습니다. **그냥 자르면 안 됩니다 — 새 훅을 붙여야 해요.**

| 파생 | 원본 구간 | 새 훅 | 포맷 |
|---|---|---|---|
| 숏폼 A | 정리 구간(8:30~) | "25개월 데려가도 되나 직접 가봤어요" | F1 검증 리스트 |
| 숏폼 B | 작은 위기(5:30~) | "여기서 애가 울기 시작했는데" | F2 공감 |
| 숏폼 C | 준비 구간(0:45~) | "이거 안 챙기면 30분 만에 집 옵니다" | F5 준비물 |
| 숏폼 D | 도착 첫 반응(3:00~) | "처음 본 순간 표정" | F4 비포/애프터 |

각 숏폼은 **끝에 "전체 영상은 프로필 링크"**로 롱폼 유입을 만듭니다.
반대로 롱폼 설명란에는 인스타 계정을 넣어 순환시키세요.

## 편집 순서 (실제 작업 60~90분)

1. 프록시 생성 + 컨택트시트 → Claude에게 업로드 (`pipeline/WORKFLOW.md`) — 5분
2. Claude가 EDL·자막·본문 산출 — 대기 시간 없음
3. 캡컷/VLLO에서 EDL대로 컷 배치 — 25분
4. 자막 `.srt` 임포트 후 스타일만 적용 — 10분
5. 음악 큐 시트대로 BGM 배치 + 현장음 볼륨 조정 — 10분
6. 렌더 + 업로드 — 15분
7. 숏폼 4편은 같은 타임라인에서 구간 복사 → 9:16 크롭 — 20분
