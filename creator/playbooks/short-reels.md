# 숏폼 포맷 5종 (릴스·쇼츠)

길이 기준: **15~40초**가 완주율이 가장 높습니다. 정보량이 많아도 45초를 넘기지 마세요.
넘칠 것 같으면 편을 나누는 게 낫습니다 (그리고 "2편은 프로필에" 로 체류를 만듭니다).

각 포맷 표의 `장치` 열은 `strategy/02-growth-engine.md`의 참여 장치입니다. **매 편 최소 3개.**

---

## F1. 검증 리스트형 — P1 나들이 (주력, 저장 폭발)

가장 많이 쓸 포맷입니다. 0~2세 부모가 궁금해하는 항목을 순서대로 체크합니다.

| 구간 | 화면 | 자막 | 장치 |
|---|---|---|---|
| 0.0–1.5s | 아이가 이미 그 공간에서 움직이는 컷 | **"25개월 데리고 가도 되나 직접 가봤어요"** | 훅 |
| 1.5–3.5s | 공간 전경 (핸드헬드 패닝) | "체크할 건 7개, 근데 5번에서 좀 놀랐어요" | 약속 + 긴장 |
| 3.5–6s | 수유실 내부 | "1. 수유실 ✅ 근데 의자가 2개뿐" | 보상1 |
| 6–8.5s | 기저귀 갈이대 | "2. 기저귀대 ✅ 3층에만 있어요" | |
| 8.5–11s | 유모차로 문 통과하는 발치 컷 | "3. 유모차 그대로 진입 ✅" | |
| 11–13.5s | 이유식 데우는 장면 | "4. 이유식 반입 ✅ 전자레인지도 빌려줌" | |
| 13.5–17s | 소음 큰 구간, 아이 표정(뒷모습) | **"5. 소음… 낮잠은 포기하세요"** | 반전(=훅 회수) |
| 17–20s | 주차장→입구 걷는 컷 | "6. 주차 5분 거리, 유모차로 살짝 힘듦" | |
| 20–23s | 계산·영수증 | "7. 총 OO,OOO원 (2시간)" | |
| 23–27s | 나오는 뒷모습 | "결론: 낮잠 끝난 오후에 가세요 / 저장해두고 가기 전에 확인하세요" | **저장** |
| 27–29s | 다음 장소 티저 2초 | "다음은 처음으로 기차 타고 갑니다" | 콜드오픈 |

- **고정 댓글**: "여기 위치 궁금하신 분 '위치'라고 DM 주세요 🙌 / 이런 데 또 아시는 분 댓글 주세요, 다음에 갈게요" → **DM + 댓글**
- 항목마다 화면 좌상단에 `1/7` 카운터를 띄우면 "몇 개 남았지"가 완주율을 올립니다.

## F2. 공감 스킷형 — P2 복직맘 현실 (공유 폭발)

정보가 아니라 **감정**입니다. 공유(DM)를 노리는 포맷.

| 구간 | 화면 | 자막 |
|---|---|---|
| 0–2s | 퇴근길 엘리베이터 / 현관 도어락 소리 | **"복직하고 제일 무서운 순간"** |
| 2–5s | 문 여는 순간, 아이 뒷모습 | "문 열었을 때 애가 나를 안 볼 때" |
| 5–12s | 실제 그 장면 (자막으로 속마음) | "3초쯤 나를 안 보다가" / "천천히 고개를 돌리는데" |
| 12–18s | 아이가 다가옴 (손·발 컷) | "그 3초가 하루 중 제일 길어요" |
| 18–24s | 안기는 순간, 부모 표정 | "오늘도 다행히 알아봐줬다" |
| 24–27s | 정지 + 텍스트 | **"복직맘들 다 알죠 이 기분"** |

- **공유 트리거**: 마지막 자막을 "나만 그런 거 아니죠?" 계열로 마무리
- **댓글 트리거**: 고정 댓글 "복직 몇 개월차세요? 저는 3개월차요"
- BGM은 잔잔하게, **아이 소리(현장음)를 살리세요.** 이 포맷의 핵심은 현장음입니다.

## F3. 후회템/인생템형 — P3 육아템 (협찬 전환 자산)

**단점을 먼저** 말하는 게 이 포맷의 전부입니다.

| 구간 | 화면 | 자막 |
|---|---|---|
| 0–2s | 제품을 던지듯 내려놓는 컷 | **"3주 써보고 솔직하게 말할게요"** |
| 2–5s | 제품 클로즈업 | "먼저 단점부터요" |
| 5–11s | 불편했던 실제 장면 | "① 세척이 진짜 번거로워요" / "② 25개월엔 아직 큼" |
| 11–15s | 전환 | "근데 이거 하나 때문에 계속 씁니다" |
| 15–24s | 결정적 장면 (비포/애프터) | "아침에 8분이 줄어요" |
| 24–28s | 결론 | "이런 분한테만 추천: [구체적 조건]" |

- **저장 트리거**: "지금 사지 마시고 저장해뒀다가 [조건]일 때 사세요"
- 협찬일 경우 **0~3초 자막에 "#광고" 노출** (`strategy/04-monetization.md`)

## F4. 비포/애프터·타임랩스형 (완시청률 최고)

"결과가 궁금해서" 끝까지 봅니다. 만들기도 가장 쉬워요.

- 0–2s: **결과를 먼저 1초 보여주고** 되감기 → "어떻게 이렇게 됐냐면"
- 2–20s: 과정 압축 (2~4배속, 타임랩스)
- 20–25s: 결과 다시, 이번엔 온전히
- 소재: 등원 준비 8분 / 이유식 한 주 만들기 / 놀이방 정리 / 아이 낮잠 재우기 40분→25초

**루프 설계**: 마지막 프레임 = 첫 프레임. 그대로 무한 반복됩니다.

---

## F5. 지도·리스트형 (저장률 1위, 촬영 부담 최소)

기존에 찍어둔 클립 여러 개를 모아 만듭니다. **새 촬영이 필요 없어서** 바쁜 주의 구원투수.

- 0–2s: "서울에서 0~2세 데리고 갈 만한 곳 5" + 지도 그래픽
- 2–24s: 장소당 4초 (클립 2초 + 핵심 정보 자막 2초)
- 24–28s: "다 저장해두세요 / 5곳 위치는 고정 댓글에"
- **재활용 원칙**: 기존 F1 릴스 5편 → F5 1편. 한 달에 한 번 반드시 만드세요. 저장 폭탄입니다.

## 포맷 선택 기준

| 상황 | 포맷 |
|---|---|
| 주말에 어디 다녀왔다 | F1 |
| 특별한 사건·감정이 있었다 | F2 |
| 새 제품을 3주 이상 썼다 | F3 |
| 과정이 있는 반복 일과 | F4 |
| **이번 주 촬영 못 했다** | F5 (기존 클립 재활용) |

- **9:16 세로, 1080×1920.** 가로로 찍은 원본은 크롭보다 **상하 여백에 정보를 넣는 편집**이 낫습니다.
