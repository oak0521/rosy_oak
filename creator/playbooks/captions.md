# 본문 문안 템플릿 (인스타 / 유튜브)

## 인스타그램 릴스 본문

### 구조

```
[1행] 훅 반복 또는 확장     ← "더보기" 전에 보이는 유일한 줄. 여기서 승부
[공백]
[2~4행] 맥락·정보 (짧은 문장, 줄바꿈 많이)
[공백]
[행동 유도 1개]            ← 저장 / 댓글 / DM 중 하나만
[공백]
[해시태그 8~15개]
```

**핵심 원칙**
- 첫 줄에 정보를 다 쓰지 마세요. "더보기"를 누르게 만드는 것 자체가 체류시간입니다.
- 행동 유도는 **하나만**. 저장·댓글·DM·팔로우를 다 요청하면 아무것도 안 합니다.
- 문단마다 줄바꿈. 모바일에서 빽빽한 텍스트는 안 읽힙니다.
- 협찬이면 **첫 줄에 `#광고`** (`strategy/04-monetization.md`)

### 완성 예시 — F1 검증 나들이

```
25개월 데리고 가도 되나 직접 확인하고 왔어요 🍼

수유실부터 유모차 동선까지 7개 항목 다 봤는데
5번(소음)에서 좀 놀랐습니다.

낮잠 시간이랑 겹치면 진짜 힘들어요.
오후에 가시는 걸 추천드려요.

총 2시간 / OO,OOO원

📌 저장해두고 가시기 전에 한 번 확인하세요

.
.
#25개월 #영아맘 #복직맘 #아기랑나들이 #유모차나들이
#수유실있는곳 #기저귀갈이대 #아기랑갈만한곳 #서울나들이
#육아일상 #워킹맘 #아들맘 #주말나들이
```

### 완성 예시 — F2 공감

```
문 열었을 때 애가 나를 안 보던 3초

복직 3개월차인데
아직도 그 순간이 제일 무서워요.

오늘은 다행히 알아봐줬습니다.

복직 몇 개월차세요? 저는 3개월요 👇

.
.
#복직맘 #워킹맘 #육아일상 #25개월 #복직준비
#어린이집적응기 #엄마의하루 #아들맘 #육아공감
```

### 해시태그 전략

**개수**: 8~15개. 30개 꽉 채우는 건 스팸 신호로 읽힐 수 있습니다.

**구성 비율**
| 유형 | 개수 | 예시 | 목적 |
|---|---|---|---|
| 대형 (게시물 50만+) | 2~3 | #육아일상 #워킹맘 | 넓은 풀 (경쟁 심함) |
| 중형 (5만~50만) | 4~6 | #복직맘 #아기랑나들이 #25개월 | **실제 도달의 주력** |
| 소형 (5만 미만) | 3~5 | #수유실있는곳 #영아나들이 | 상위 노출 가능 |
| 브랜드 태그 | 1~2 | #수달이네주말보고서 | 시리즈 아카이브 |

**시리즈 전용 해시태그를 반드시 하나 만드세요.** 그 태그를 누르면 내 시리즈만 모여 나옵니다
— 이게 계정 내 체류시간을 만드는 장치입니다.

**금지**: 관련 없는 인기 태그, #선팔맞팔 #소통 계열 (참여율만 망가집니다)

## 유튜브 (롱폼)

### 제목 공식

```
[구체적 대상] + [구체적 행동] + [결과 암시]
```

- ❌ "아기와 주말 브이로그"
- ✅ "25개월 아기 데리고 처음 기차 탔다가 생긴 일 | 복직맘 주말 브이로그"
- ✅ "0~2세도 갈 수 있는 서울 실내 나들이 5곳 (수유실·기저귀대 직접 확인)"

검색 유입을 노린다면 **개월수·지역·시설명**을 제목에 넣으세요. 이게 1년 뒤 유입을 만듭니다.

### 설명란 구조

```
[1~2행] 영상 요약 (검색 노출에 쓰임)

📍 오늘 다녀온 곳: OOO (서울 OO구)
- 수유실 ✅ / 기저귀 갈이대 ✅(3층) / 유모차 진입 ✅
- 이유식 반입 ✅ / 소음 ⚠️ / 주차 도보 5분
- 총 비용: OO,OOO원 (2시간, 성인 2 + 영아 1)

⏱ 챕터
0:00 처음 본 순간
0:20 오늘 어디 가냐면
0:45 짐 싸기 (이것만은 챙기세요)
2:00 이동
3:00 도착, 첫 반응
5:30 여기서 문제가 생겼어요
7:00 결국 이렇게 해결했습니다
8:30 7개 항목 정리 + 총비용
9:30 다음 편 예고

🍼 25개월 아들과 복직 3개월차 엄마의 기록입니다.
   0~2세 아이와 갈 수 있는 곳만 직접 확인해서 올려요.

📷 인스타그램 @OOO — 짧은 영상은 여기에 먼저 올라갑니다

#육아브이로그 #25개월 #복직맘 #아기랑나들이
```

**챕터는 반드시 넣으세요.** 0:00으로 시작해야 인식됩니다.

### 고정 댓글 (댓글 유도 장치)

```
여기 위치랑 주차 정보는 이 댓글에 정리해뒀어요 👇
[주소 / 주차 / 운영시간]

혹시 0~2세 데리고 갈 만한 곳 아시는 데 있으면 알려주세요.
다음 영상에서 직접 가보고 확인해서 올릴게요 🙌
```

→ 다음 콘텐츠 소재까지 확보되는 구조입니다.

### 유튜브 쇼츠 (릴스 재활용)

- 제목 = 훅 그대로 (40자 이내)
- 설명 3줄 + 해시태그 3~5개 (`#Shorts` 필수)
- **음원 주의**: 인스타 트렌딩 오디오를 쓴 릴스를 그대로 유튜브에 올리면 저작권 클레임·수익화 차단
  대상이 됩니다. → `subtitles-and-music.md`의 이중 배포 규칙 참고
