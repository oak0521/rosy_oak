# 자막 · 음악 규칙

## 자막

### 왜 중요한가
릴스 시청의 상당 비율이 **무음**입니다. 그리고 자막은 정보 전달 수단이기 전에
**시선을 화면에 고정시키는 장치**입니다. 자막이 바뀌는 순간마다 이탈이 지연됩니다.

### 규칙

| 항목 | 기준 |
|---|---|
| 한 화면 글자수 | **최대 16자 × 2줄** (한글 기준) |
| 표시 시간 | 1.5~2.5초. **4초 이상 금지** |
| 줄바꿈 | 의미 단위로. "복직하고 제일 / 무서운 순간" ❌ → "복직하고 / 제일 무서운 순간" ✅ |
| 위치 | 하단에서 **480px 위** (1080×1920 기준, 화면 높이 약 70~75%). 상단 15%·하단 20%는 플랫폼 UI가 가립니다 |
| 폰트 | 굵은 고딕 (Pretendard Bold, 에스코어드림 7, 나눔스퀘어 ExtraBold) |
| 크기 | 1080×1920 기준 **58~72px** |
| 대비 | 흰 글자 + 검정 외곽선 2~3px, 또는 반투명 검정 박스 |
| 강조 | 핵심 단어만 **노란색 또는 확대**. 편당 3~4회 이하 |

### 톤

- 구어체. "~했습니다" 보다 "~했어요"
- 문장 부호 최소화. 마침표는 대부분 생략
- 이모지는 편당 2~3개까지. 남용하면 유치해집니다
- **속마음 자막**이 브이로그의 핵심입니다.
  화면: 아이가 밥을 던짐 / 자막: "저건 오늘 세 번째예요"

### 자막 유형 3가지를 구분해서 쓰기

| 유형 | 스타일 | 용도 |
|---|---|---|
| **훅 자막** | 최대 크기, 상단 고정, 영상 내내 유지 가능 | 0~3초 |
| **내레이션 자막** | 중앙, 표준 크기 | 정보 전달 |
| **속마음 자막** | 작게, 다른 색, 손글씨 느낌 | 감정·유머 |

세 가지가 시각적으로 구분되면 영상이 훨씬 프로처럼 보입니다.

### SRT 파일 활용

Claude가 `.srt`로 자막을 산출합니다. 캡컷·프리미어·VLLO 모두 SRT 임포트를 지원하니
**타이핑할 필요가 없습니다.** 임포트 후 스타일만 일괄 적용하세요 (2분).

```srt
1
00:00:00,000 --> 00:00:01,500
25개월 데리고 가도 되나
직접 가봤어요

2
00:00:01,500 --> 00:00:03,500
체크할 건 7개
근데 5번에서 좀 놀랐어요
```

## 음악

### 플랫폼별 전략 (⚠️ 가장 흔한 사고 지점)

**인스타 릴스**: 인스타 앱 내 음원 라이브러리의 **트렌딩 오디오**를 쓰세요.
트렌딩 사운드는 알고리즘 추가 노출을 받고, 유행 오디오를 초반 5초에 쓰면 도달이 유의미하게 오릅니다.

**유튜브 쇼츠**: 인스타 트렌딩 오디오를 **그대로 가져오면 안 됩니다.**
저작권 클레임 → 수익화 차단 또는 영상 차단이 걸립니다.

**해결책 — 오디오를 분리해서 두 벌 만드세요**
```
편집 타임라인 (BGM 트랙 분리)
   ├─ 인스타 버전: BGM 트랙 음소거 → 인스타 앱에서 트렌딩 오디오 얹기
   └─ 유튜브 버전: 저작권 안전 음원 트랙 켜서 렌더
```
현장음(아이 목소리)은 두 버전 모두 유지합니다. 이게 진짜 자산이에요.

### 저작권 안전 음원 (유튜브용)

- **YouTube 오디오 보관함** — 가장 안전. 수익화 가능 표시 확인
- **Epidemic Sound / Artlist** — 유료 구독. 월 2편 이상 롱폼 만들면 값어치 함
- **Uppbeat / Pixabay Music** — 무료. 출처 표기 조건 확인 필수

> 무료 음원이라도 **"YouTube에서 수익 창출 가능"**인지 반드시 확인하세요.
> "무료 다운로드"와 "상업적 이용 가능"은 다른 얘기입니다.

### 음악 큐 시트 (Claude가 산출하는 형식)

| 구간 | 무드 | BPM | 볼륨 | 비고 |
|---|---|---|---|---|
| 0:00–0:20 | 경쾌·기대 | 110~125 | -18dB | 콜드오픈. 현장음 우선 |
| 0:20–2:00 | 밝고 가벼움 | 100~115 | -20dB | 나레이션 구간, 더 낮게 |
| 5:30–7:00 | 잔잔·약간 무거움 | 70~85 | -24dB | **위기 구간. 현장음 살리기** |
| 7:00–8:30 | 따뜻·상승 | 95~110 | -18dB | 해결. 여기서 음악이 올라와야 감정이 붙음 |
| 9:30–10:00 | 여운 | 70~90 | -20dB | 페이드아웃 |

### 음량 규칙

- **현장음(아이 목소리)이 주인공입니다.** BGM은 -18 ~ -24dB로 깔아 두는 배경일 뿐.
- 아이가 말하거나 웃는 순간엔 BGM을 **추가로 6dB 더 내리세요** (덕킹).
- 최종 라우드니스: **-14 LUFS** 근처 (유튜브·인스타 공통 권장선)
- 무음 구간을 두려워하지 마세요. 결정적 순간 직전 0.5초 무음은 강력한 강조 장치입니다.

### 효과음 (SFX)

과하면 유치해지지만, 아래 3개만 절제해서 쓰면 완성도가 확 올라갑니다.
- 컷 전환 whoosh (편당 2~3회)
- 강조 팝 (자막 등장 시, 편당 3~4회)
- 정적 타격음 (반전 자막 등장 시, 편당 1회)
