# 예제 — `/longform` 한 번의 실제 산출물 전체

가상의 주말 나들이("25개월 첫 키즈카페, 낮잠 어긋나 30분 울었고 볼풀에서 회복,
수유실 의자 2개, 2시간 34,000원")로 실제로 돌려서 나온 파일들입니다.
원본 8개 클립(해상도·fps 제각각) → 롱폼 2분37초 + 숏폼 4편이 나왔습니다.

| 파일 | 내용 |
|---|---|
| `edl.json` | 롱폼 컷 15개. 어느 클립 몇 초를 어떤 순서로, 각 컷의 역할 |
| `longform.srt` | 롱폼 자막 34블록 |
| `shorts.json` | 숏폼 4편 파생 명세 (구간·9:16 변환 방식·새 훅·참여 장치) |
| `shorts/*.srt` | 숏폼별 자막 — **각각 새 훅으로 시작**합니다 |
| `captions.md` | 유튜브 제목·챕터·설명란·고정 댓글 + 릴스 4편 본문·해시태그 + 발행 순서 |
| `music-cue.md` | 구간별 무드·BPM·볼륨, 플랫폼별 음원 처리 |

## 이 예제가 보여주는 것

**롱폼 1편 → 숏폼 4편이 어떻게 갈라지는지**

| 숏폼 | 롱폼 구간 | 새 훅 | 노리는 신호 |
|---|---|---|---|
| A 검증7항목 | 2:05–2:33 (정리) | "25개월 데리고 가도 되나 직접 가봤어요" | 저장 |
| B 30분울었다 | 0:55–1:20 (위기) | "30분을 울었는데 제 잘못이었어요" | 공유 |
| C 짐싸기5개 | 0:12–0:28 (준비) | "이거 안 챙기면 30분 만에 집 옵니다" | 저장 |
| D 첫반응 | 0:34–0:51 (도착) | "키즈카페 처음 본 25개월의 1분" | 완시청·루프 |

**그냥 자르는 게 아닙니다.** 같은 영상에서 나왔지만 각각 다른 훅으로 시작하고
다른 행동을 유도합니다. 알고리즘이 중복으로 보지 않는 이유예요.

## 직접 돌려보려면

`--dry-run` 을 붙이면 원본 영상 없이도 어떤 명령이 실행될지 확인할 수 있습니다.

```bash
cd creator/pipeline/example
python3 ../scripts/render.py longform edl.json --dry-run
```
