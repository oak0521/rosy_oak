# 윈도우용 — 터미널 없이 더블클릭으로

명령어를 칠 필요 없습니다. 아래 세 파일만 쓰시면 됩니다.

| 파일 | 언제 | 하는 일 |
|---|---|---|
| `0_최초설치.bat` | **딱 한 번만** | FFmpeg·Python 설치. 끝나면 컴퓨터 재시작 |
| `1_준비하기.bat` | 촬영본을 옮긴 뒤 | 컨택트시트·프록시 생성 → 폴더가 저절로 열림 |
| `2_영상만들기.bat` | Claude 가 준 json 을 받은 뒤 | 실제 영상 렌더 → 폴더가 저절로 열림 |

## 쓰는 법

**처음 한 번**
1. `0_최초설치.bat` 더블클릭 → 설치 중 "예/Y" 를 물어보면 누르기
2. 컴퓨터 재시작 (이걸 해야 인식됩니다)

**매주 반복**
1. 아이폰 영상을 컴퓨터 폴더에 복사 (예: `D:\옥진작업\클로드코드\insta_siu`)
2. `1_준비하기.bat` **더블클릭** → 영상 폴더를 창에 **끌어다 놓고** Enter
3. 저절로 열린 폴더의 `jpg` 파일들을 Claude 채팅에 **끌어다 놓기**
4. 채팅에 입력: `/longform` + 그날 있었던 일 설명
5. Claude 가 준 `edl.json` 을 컴퓨터에 저장
6. `2_영상만들기.bat` **더블클릭** → 그 json 을 창에 **끌어다 놓고** Enter
7. 저절로 열린 폴더에 완성 영상이 있습니다

> 폴더나 파일을 검은 창에 끌어다 놓으면 경로가 자동으로 입력됩니다. 타이핑할 필요 없어요.

## 완성된 파일 구분법

| 파일 이름 | 어디에 올리나 |
|---|---|
| `이름_무음_인스타용.mp4` | **인스타 릴스.** 올린 뒤 앱 안에서 트렌딩 오디오를 얹으세요 |
| `이름.mp4` | **유튜브 쇼츠 / 롱폼.** 그대로 업로드 |
| `이름_master_자막없음.mp4` | 올리지 마세요. 숏폼 만들 때 쓰는 원본입니다 |

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| "FFmpeg 이 없습니다" | `0_최초설치.bat` 실행 후 **재시작** |
| "Python 이 없습니다" | 같음. 직접 설치했다면 "Add python.exe to PATH" 체크 필요 |
| 창이 순식간에 닫힘 | 파일을 **더블클릭**했는지 확인 (오른쪽 클릭 → 열기도 가능) |
| 글자가 깨져 보임 | 기능엔 문제 없습니다. 그대로 진행하세요 |
| 그 외 오류 | 검은 창의 메시지를 **그대로 복사해서 Claude 채팅에 붙여넣기** |

## 이것도 부담스러우면

`2_영상만들기.bat` 을 아예 안 써도 됩니다.
Claude 가 주는 `edl.json` 은 **사람이 읽는 작업 지시서**이기도 해서,
캡컷(CapCut)을 열고 표에 적힌 대로 컷을 배치하면 결과는 같습니다 (25분).
자막 `.srt` 파일은 캡컷에서 그대로 불러올 수 있어 타이핑이 필요 없습니다.

캡컷 자막 불러오기: 타임라인 → 텍스트 → 자막 가져오기 → `.srt` 선택
