# 육아 인플루언서 콘텐츠 시스템

아이폰으로 찍은 원본 영상·사진을 → **기획 → 편집 설계 → 자막 → 음악 → 롱폼 → 숏폼 재편집 → 인스타/유튜브 본문**까지
반복 가능한 파이프라인으로 돌리기 위한 저장소입니다.

## 전제 (2026-08 확정)

| 항목 | 값 |
|---|---|
| 아이 연령 | 0~2세 (영아) |
| 주력 플랫폼 | **인스타그램 릴스 중심** + 유튜브 쇼츠 병행, 유튜브 롱폼은 아카이브·검색 자산 |
| 주당 가용 시간 | **4~6시간** (복직 상태) |
| 목표 발행량 | 릴스 **주 3편** + 롱폼 **월 2편** (롱폼 1편에서 숏폼 3~4편 재활용) |
| 노출 수위 | **미확정** — 기존 계정은 전면공개. `strategy/05-child-safety.md`의 A/B/C 티어와 하이브리드 권장안 참고 |
| 수익 목표 | 협찬(영유아 카테고리) → 공동구매 → 자체 상품 |

## 이 저장소가 하는 일과 못 하는 일

**Claude가 해주는 것 (당신 시간 안 듦)**
- 콘텐츠 기획 — 어떤 클립으로 어떤 포맷을 만들지, 훅은 뭘로 할지
- 컷 편집 설계 — 몇 초에 뭘 붙일지 초 단위 EDL(편집 결정 리스트)
- 자막 전문 + 타이밍 (`.srt` 파일로 바로 산출)
- 음악 큐 시트 — 어느 구간에 어떤 무드, 어디서 볼륨 다운
- 숏폼 재편집 설계 — 롱폼 어느 구간을 잘라 어떤 새 훅을 붙일지
- 인스타/유튜브 본문 문안, 해시태그, 썸네일 문구, 고정 댓글

**당신(또는 스크립트)이 해야 하는 것**
- 촬영
- 렌더 버튼 — 실제 영상 합성. `pipeline/scripts/`의 ffmpeg 스크립트로 자동화하거나,
  캡컷/VLLO에 EDL대로 옮기기 (설계가 나와 있으면 15~25분)
- 업로드·댓글 응대

> 이 세션(원격 컨테이너)에서 4K 원본 수십 GB를 렌더하는 건 비현실적입니다.
> 대신 `pipeline/scripts/proxy.sh`로 **저용량 프록시 + 컨택트시트**를 만들어 올리면
> Claude가 실제 화면을 보고 기획합니다. 렌더는 당신 컴퓨터에서 같은 스크립트로 돌립니다.

## 어디부터 읽나

1. `strategy/01-positioning.md` — 계정 컨셉 확정 (**여기부터**)
2. `strategy/05-child-safety.md` — 얼굴 공개 결정 (미룰수록 되돌리기 어려움)
3. `pipeline/WORKFLOW.md` — 원본 올리고 결과 받는 실제 절차
4. `ops/weekly-routine.md` — 주 4~6시간을 어떻게 쪼개나
