# 성과 지표 — 무엇을 보고 무엇을 무시할 것인가

## 보지 말아야 할 것

**좋아요 수.** 2026년 알고리즘에서 도달 기여도가 가장 낮고, 심리적으로만 소모됩니다.
**팔로워 수**도 주 단위로는 보지 마세요. 월 단위로만 확인합니다.

## 주간에 볼 지표 (인스타 인사이트)

| 지표 | 어디서 | 판단 기준 | 나쁠 때 고칠 것 |
|---|---|---|---|
| **3초 유지율** | 릴스 > 시청 유지 | 60% 미만이면 실패 | **훅** (`playbooks/hooks.md`) |
| **평균 시청 시간 / 길이** | 릴스 인사이트 | 50% 미만이면 실패 | 중간 구조, 자막 리듬, 길이 |
| **저장 / 도달** | 릴스 인사이트 | **1% 이상 목표** | 저장 트리거, 정보 밀도 |
| **공유 / 도달** | 릴스 인사이트 | 0.5% 이상 목표 | 감정 훅, 대변형 문안 |
| **팔로워 아닌 계정 도달 비율** | 릴스 인사이트 | 70% 이상이면 확산 중 | 낮으면 주제가 너무 좁음 |
| **프로필 방문 / 도달** | 인사이트 > 계정 | 2% 이상 | 프로필 유도 자막, 고정 3개 |

> **저장률이 이 계정의 북극성 지표입니다.**
> 2층(정보성) 콘텐츠가 제대로 작동하는지를 저장률 하나로 알 수 있고,
> 저장률이 높은 계정은 팔로워가 적어도 협찬 단가가 높게 잡힙니다.

## 월간에 볼 지표

- 팔로워 순증
- ER = (좋아요+댓글+저장+공유) / 도달 — **미디어킷에 들어가는 숫자**
- 팔로워 구성 (성별·연령·지역) — 협찬 제안의 핵심 근거
- 상위 3개 콘텐츠의 공통점 → 다음 달 편성에 반영

## 판단 규칙

| 상황 | 해석 | 조치 |
|---|---|---|
| 3초 유지율 ↓, 나머지 정상 | 훅 문제 | 훅 유형을 바꿔 2편 테스트 |
| 3초 유지율 ↑, 완주율 ↓ | 훅은 좋은데 내용이 못 따라감 | 중간 보상 배치, 길이 단축 |
| 도달 ↑, 저장 ↓ | 재미는 있는데 쓸모가 없음 | 정보 밀도 올리기 (2층 강화) |
| 저장 ↑, 팔로워 ↓ | 콘텐츠는 저장되는데 계정 이유가 없음 | 1층(정체성) 콘텐츠 비중 확대 |
| 전부 ↓ 3편 연속 | 알고리즘이 주제를 재학습 중 | **바꾸지 말고 유지.** 4주 뒤 재판단 |
| 특정 1편만 급상승 | 그 포맷이 통한 것 | 같은 포맷으로 즉시 2편 더 |
