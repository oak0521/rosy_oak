# 주간 운영 루틴 (가용 4~6시간)

복직 상태에서 주 3편을 유지하는 유일한 방법은 **촬영과 편집을 분리**하고,
**항상 재고 2편을 남겨두는 것**입니다.

## 시간 배분

| 요일 | 시간 | 할 일 | 소요 |
|---|---|---|---|
| 평일 매일 | 아무 때나 | **촬영만.** 편집 생각 안 함. 하루 2~3클립 | 0분 (일상 중) |
| 평일 밤 1회 | 아이 재운 뒤 | 스토리 5컷 + 댓글 답글 전부 | 20분 |
| **토 오전** | 아이 나들이 | 샷 리스트대로 촬영 | 30분 (나들이 중) |
| **토 밤** | 재운 뒤 | `prep.sh` 실행 → Claude에 업로드 → 기획·자막·본문 수령 | 30분 |
| **일 오전** | 아이 낮잠 | 렌더 또는 캡컷 편집 → 릴스 3편 + 롱폼 1편 완성 | 2시간 |
| **일 밤** | 재운 뒤 | 예약 발행 걸어두기 + 다음 주 소재 메모 | 30분 |
| 평일 분산 | 출퇴근길 | 댓글·DM 응대 | 15분×3 |

합계 **약 4시간 30분**. 나들이 촬영 30분은 어차피 나가 있는 시간이라 추가 부담이 아닙니다.

## 핵심 원칙 4가지

### 1. 촬영과 편집을 절대 같은 날 하지 않는다
찍으면서 편집을 생각하면 촬영이 느려지고, 아이와의 시간이 촬영 노동이 됩니다.
평일엔 무조건 **찍기만** 하세요. 쓸지 말지는 주말의 내가 정합니다.

### 2. 재고 2편 원칙
아이가 아프거나 야근한 주는 반드시 옵니다. 그때 업로드가 끊기면 알고리즘이 계정을 비활성으로 봅니다.
**항상 발행 대기 상태인 완성본 2편을 확보**해두세요.
잘 만든 주에 4편을 만들어 2편만 올리고 2편은 재고로 넘기는 식입니다.

### 3. 바쁜 주는 F5 (지도·리스트형)
새 촬영 없이 기존 클립만으로 만드는 포맷입니다. 저장률도 가장 높아요.
`playbooks/short-reels.md` 의 F5 참고. **월 1회는 의무적으로** 넣으세요.

### 4. 완성도보다 발행 주기
80% 완성도로 주 3편 > 100% 완성도로 주 1편. 확실히 그렇습니다.
컷이 조금 거칠어도 훅과 자막만 살아 있으면 도달은 나옵니다.

## 예약 발행

인스타·유튜브 모두 예약 발행을 지원합니다. **일요일 밤에 한 주치를 다 걸어두세요.**
평일에 "올려야 하는데" 하는 압박이 사라지는 것만으로 지속 가능성이 크게 올라갑니다.

- 인스타: 프로페셔널 계정 → 게시물 작성 → 고급 설정 → 일정 예약
- 유튜브: 업로드 → 공개 설정 → 예약

**예약할 수 없는 것**: 스토리, 댓글 응대. 이건 매일 20분 확보하세요.

## 소재 재고 관리

핸드폰 메모에 이것만 유지하세요.

```
[촬영 완료 - 편집 대기]
- 08/23 놀이터 미끄럼틀 처음 혼자 탐 → F2 공감
- 08/24 이유식 던짐 3회 → F2 or F4

[아이디어 - 미촬영]
- 비 오는 날 실내 무료 공간 3곳 → F1
- 후회한 육아템 5개 → F3
- 8월 나들이 총정리 → F5

[발행 재고]
- 릴스 A (완성) 
- 릴스 B (완성)
```

## 번아웃 방지

- **아이와의 시간이 촬영에 종속되면 그만두세요.** 카메라를 든 시간이 노는 시간보다 길어지는 순간이 신호입니다.
- 한 달에 한 주는 **촬영 없는 주**로 비우세요. 재고 2편으로 버팁니다.
- 조회수가 안 나오는 편이 반드시 있습니다. 3편 연속 부진해도 컨셉을 바꾸지 마세요 —
  알고리즘이 계정 주제를 학습하는 데 시간이 걸립니다. 판단은 `metrics.md` 기준으로 **월 단위**로.
