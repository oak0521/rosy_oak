## 폴더 구성
- `source/` 원본 6개 (네이버 검색광고 일별 CSV, GFA CSV, 메타 자사몰·스마트스토어 xlsx, 스마트스토어 매출 아넬라·로지 xlsx). 기간 10/1~10/28.
- `scripts/` 엑셀 생성 스크립트. `bash scripts/run_all.sh` 로 결과 파일을 다시 만듭니다 (pandas, openpyxl 필요).
- `build/` 중간 산출물 (git 제외).

## 이어서 작업하는 법
- 10/29~10/31 확정 실적: `source/`의 원본을 10/1~10/31 전체 기간 파일로 교체 → `scripts/make_data.py`/`build_data.py`의 기간 구분(P1~P5)과 `build_wb.py`의 `가정` 시트 기간·잔여일수를 맞춘 뒤 `run_all.sh`.
- 행사일수·예산·KPI 하한 같은 가정은 엑셀의 `가정`, `목표_11-12월` 시트 노란 칸에서 직접 수정합니다. 스크립트 값은 초기 입력값입니다.
- 스마트스토어 매출은 상품명에 "공동구매"가 들어간 상품을 일반 집계에서 제외합니다 (`데이터_SS상품`의 구분 수식, `make_data.py`).

## 집계 기준 요약
- 광고 매출·구매: 네이버 `구매완료` 컬럼, 메타 `구매`/`구매 전환값`. 광고비는 원본 그대로.
- 브랜드검색 비용: 월 88만원(2,640,000원/90일 기준)을 일할 안분.
- 10월 목표는 별도로 없어 4분기 KPI 보고안의 ROAS 하한(아넬라 850%, 로지 420%)과 10월 예산을 소급 적용.
- 메타 스스(로지) 10/24~25 전환값은 같은 이틀 스토어 결제보다 커서 이상치로 표기하고 목표 산정에서 제외 (`점검` 시트).
