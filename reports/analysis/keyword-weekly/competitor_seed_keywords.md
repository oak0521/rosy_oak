# 경쟁사 키워드 조사용 시드 목록 (2026-11-24 작성)

**왜 필요한가** — 키워드·검색어 리포트에는 "우리 광고가 노출된 검색어"만 있어서, 경쟁사는 쓰는데 우리는 노출조차 못 하는 키워드(갭)는
데이터로 알 수 없다. 클라우드 세션은 사용자 크롬에 연결되지 않고 네이버 접속도 막혀 있어(프록시 403), 사용자 PC의 **Claude in Chrome
확장이 연결된 세션**(또는 수동 캡처)에서 아래 키워드를 네이버 모바일 검색으로 조사해야 한다. 결과를 이 저장소 세션에 붙여 주면
`#keyword`의 "경쟁사 신호"에 반영한다.

## 수집 양식 (키워드 1개당)
1. 네이버 **모바일** 검색 결과의 **파워링크** 광고주(브랜드명)·광고 제목/문구·개수 — 로그인 없이, 같은 기기에서 2~3회 새로고침해 로테이션 확인
2. **쇼핑검색** 상위 8개 상품의 브랜드·가격·리뷰 수·광고(AD) 표시 여부
3. **아넬라/로지오가닉이 위 1·2에 노출되는지**(순위)
4. 자동완성·연관검색어 상위 5개
5. 메모: 우리에게 없는 콘텐츠 주제(블로그·카페·지식iN 상위 글 제목)

## 크롬 연결 세션에 그대로 붙여 넣을 요청문

> 위 표의 키워드를 네이버 모바일 검색에서 하나씩 검색해 "수집 양식" 1~4번을 표로 정리해 줘. 로그인·결제·계정 설정은 건드리지 말고, 광고 클릭은 하지 마(클릭 비용 발생).
> 결과는 키워드별 (경쟁 파워링크 광고주 / 쇼핑 상위 브랜드·가격 / 우리 노출 여부 / 연관검색어)로 요약하고, 경쟁사는 반복 노출되는데 우리는 안 나오는 키워드를 따로 뽑아 줘.

주의: 파워링크는 광고 로테이션·개인화 영향으로 한 번의 스냅샷은 대표성이 약하다. 여러 번 확인하고, 이건 우리 전환 데이터가 아니라 **경쟁 노출 관찰**이라는 점을 리포트에 명시한다.
