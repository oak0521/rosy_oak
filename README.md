# rosy_oak

광고대행사(서스테이너블 컨설팅)가 매주/매달 보내는 광고 성과 리포트(대시보드 캡처, 캠페인/소재별 엑셀, 월간 리포트 엑셀)를
대표 주간회의용으로 가공한 HTML 리포트 아티팩트를 관리하는 저장소입니다.

`reports/weekly-report.html` 하나가 아넬라·로지오가닉 두 브랜드의 최신 주간 리포트입니다.
상단 브랜드 탭(`.brand-chip`)으로 새 창 전환 없이 같은 화면 안에서 즉시 브랜드를 바꿀 수 있습니다.
자세한 데이터 구조와 갱신 방법은 `CLAUDE.md`를 참고하세요.

---

## `creator/` — 육아 인플루언서 콘텐츠 시스템

광고 리포트와는 별개의 라인입니다. 아이폰으로 찍은 원본 영상·사진을
기획 → 편집 설계(EDL) → 자막 → 음악 → 롱폼 → 숏폼 재편집 → 인스타/유튜브 본문까지
반복 가능한 파이프라인으로 만든 것으로, `creator/README.md` 부터 읽으면 됩니다.

`/reels`, `/longform` 슬래시 커맨드로 실행합니다 (`.claude/skills/`).
